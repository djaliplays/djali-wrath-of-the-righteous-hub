| **Feature**             | **Details**                                                                 |
|-------------------------|-----------------------------------------------------------------------------|
| **Prerequisites**       | Metamagic: Any (except Intensified Spell, see bug below)                    |
|                         | Skill Focus: Knowledge (Arcana) *or* Skill Focus: Knowledge (World)         |
|                         | 3rd level Divine *or* Arcane spells                                         |
| **Class Skills**        | Knowledge (Arcana), Knowledge (World), Lore (Nature), Lore (Religion), Persuasion, UMD |
| **BAB**                 | +0                                                                          |
| **Spellbook Selection** | Divine/Arcane of choice                                                     |
| **CL**                  | +1 to chosen Divine/Arcane                                                  |

**On Prerequisites**:

- Alchemist "extracts" don't qualify as Divine or Arcane spells

**Class Features**:

- Half-BAB progression while maintaining full spellcasting advancement.
- *Secrets* are the class's defining feature, available at odd levels and allowing feats, spells, or talents while bypassing prerequisites.

**Spell Timing**

-  A Loremaster Secret can only grant a spell of a level the character could already cast *before* taking the Loremaster level. Consequently, the earliest one can obtain a spell through Loremaster is one character level later than if it belonged to one’s own class spellbook.
