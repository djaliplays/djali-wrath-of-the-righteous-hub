#### Items { #fire-items }

There are many items with descriptions that do something on certain elemental damage. 

However, almost all require the original spell to have an elemental descriptor to work.

I have only found one item that works with converted Stalactites traps:

??? item "Call of the Fiery Things"
    {% include '_includes/call_of_the_fiery_things.md' %}

Note that the damage it deals will become (un)holy or negative due to the conversion, preventing any further possible fire synergies.
