### Elemental Conversion

Once damage has been converted to an energy type, it can be converted again to an elemental type. This affects trap damage, but not Geomancy or its damage to the caster, which remain holy, unholy or negative.

One way to achieve this is through Elemental Bloodline (Fire). Since the build already takes a dip into [Geomancer](#geo-bloodline), access to this bloodline is straightforward.

#### Reasons to convert to fire

- [Flame Curse](#std-hexes), for additional single-target damage.
- [Items](#fire-items) that trigger on fire damage.
- [Elemental Barrage](#elemental-barrage).

#### Resistances and immunities

Many demons have elemental resistances and immunities. Ascendant Element is therefore useful when converting damage to an element.

??? mythic-feature "Ascendant Element"
    {% include '_includes/ascendant_element.md' %}

Ascendant Element is available for acid, cold, electricity, fire, negative energy and sonic damage.

An alternative is the Vulnerability Curse hex. Despite its name, it does not grant vulnerability in the same way as Flame Curse; instead, it bypasses immunities and resistances.

??? hex "Vulnerability Curse"
    {% include '_includes/vulnerability_curse.md' %}

Vulnerability Curse uses a standard action and affects a single target. The traps already have a small area of effect, so the single-target limitation is relatively minor, particularly because Geomancy provides the main source of area damage.
